# Cauce

Sistema de análisis de datos para el riesgo de inundaciones. Estima con un Random Forest el nivel de riesgo (bajo, medio o alto) de un condado de EE. UU. para el año siguiente, a partir de las reclamaciones del NFIP, los eventos de NOAA y las declaratorias de FEMA.

Código fuente: https://github.com/jorgemx546/riesgo-inundaciones
